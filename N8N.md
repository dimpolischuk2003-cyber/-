# Підключення n8n і Google-таблиці

Сайт уже вміє відправляти заявки. Бракує тільки таблиці та воркфлоу.
Весь ланцюг виглядає так:

```
форма на сайті → /api/lead (функція на Vercel) → webhook n8n → Google-таблиця
```

---

## 1. Таблиця

Створіть Google-таблицю, перший аркуш назвіть **Ліди**.

У клітинку **A1** вставте рядок із файлу `n8n-headers.txt` — там 28 назв колонок,
розділених табуляцією. Google сам розкладе їх по колонках A…AB.

**Не набирайте заголовки руками.** Вони мають збігатися з ключами у воркфлоу
символ у символ, інакше n8n не знайде колонку і залишить її порожньою.
Особливо це стосується `Ім'я` — там апостроф.

Скопіюйте **ID таблиці** з адресного рядка:
`https://docs.google.com/spreadsheets/d/`**`ЦЕЙ_ДОВГИЙ_РЯДОК`**`/edit`

---

## 2. Воркфлоу

1. У n8n: **Workflows → Import from File** → виберіть `n8n-workflow.json`.
2. Відкрийте ноду **Записати в таблицю**:
   - **Credential** → підключіть свій Google-акаунт (Google Sheets OAuth2).
   - **Document** → замініть `ВСТАВТЕ_ID_ТАБЛИЦІ` на ID з кроку 1.
   - **Sheet** → має стояти `Ліди`.
   - Перевірте, що **Column to match on** = `lead_id`.
3. Збережіть і **увімкніть** воркфлоу перемикачем угорі справа.

Три ноди роблять таке: приймають заявку, перекладають технічні назви полів
у зрозумілі заголовки, записують рядок із пошуком за `lead_id`.

---

## 3. Адреса вебхука

Відкрийте ноду **Заявка з сайту** і скопіюйте **Production URL**.
Виглядає так: `https://ваш-n8n.com/webhook/vseodent-lead`

**Тестовий URL не підходить.** Той, що з `/webhook-test/`, працює лише
поки ви натиснули «Execute workflow», і мовчки ігнорує заявки решту часу.

---

## 4. Vercel

Settings → Environment Variables → додати:

| Змінна | Значення |
|---|---|
| `LEAD_WEBHOOK_URL` | Production URL з кроку 3 |
| `LEAD_WEBHOOK_SECRET` | будь-який довгий рядок — **необов'язково**, див. нижче |

Після додавання обов'язково зробіть **Redeploy**. Vercel підхоплює змінні
тільки під час збірки, без редеплою нічого не зміниться.

---

## 5. Перевірка

Заповніть форму на робочому домені до кінця.

У таблиці має з'явитися **один** рядок зі статусом «Реєстрація завершена».
Якщо рядків стало два — у ноді Google Sheets не виставлений `lead_id`
як колонка для пошуку.

Спробуйте ще раз, але зупиніться після першого кроку. Має з'явитися рядок
зі статусом «Тільки контакти» — це людина, яка залишила телефон і не дійшла
до кінця. Таких треба передзвонювати першими.

---

## Захист вебхука (рекомендую)

Адреса вебхука публічна: хто її дізнається, зможе засмічувати таблицю.

1. Придумайте довгий рядок і покладіть його у Vercel як `LEAD_WEBHOOK_SECRET`.
2. У n8n у ноді **Заявка з сайту**: Authentication → **Header Auth** →
   створіть credential з іменем заголовка `X-Vseodent-Secret` і тим самим значенням.
3. Redeploy на Vercel.

Тепер n8n відкидатиме все, що прийшло не з вашого сайту.

---

## Якщо щось не працює

**У таблиці порожньо.** Перевірте, що воркфлоу увімкнений і що у Vercel
стоїть Production URL, а не тестовий. Далі подивіться в n8n → Executions:
якщо виконань немає — запит не дійшов, шукайте проблему на боці Vercel
(Deployments → Functions → логи). Якщо виконання є, але з помилкою —
проблема в credential Google або в ID таблиці.

**Рядки дублюються.** У ноді Google Sheets не виставлена колонка для пошуку.
Має бути `lead_id`.

**Частина колонок порожня.** Заголовки в таблиці не збігаються з ключами.
Перевставте рядок із `n8n-headers.txt` у A1.

**Заявки не йдуть узагалі, а в консолі браузера видно текст «demo».**
Ви на GitHub Pages або на localhost. Реальні заявки ходять тільки з домену Vercel.
