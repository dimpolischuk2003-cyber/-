# VSEODENT — сайт курсів

Статичний сайт (HTML + CSS + JS, без збірки). Працює локально, на GitHub Pages
і на Vercel. Реєстрація на курс — форма з 3 кроків із передачею ліда у webhook.

---

## Структура

```
index.html            головна: hero, розклад, спікери, FAQ
course.html           сторінка курсу (?slug=...)
assets/css/styles.css усі стилі, розбиті на секції з коментарями
assets/js/data.js     ← ВЕСЬ КОНТЕНТ ТУТ (курси, спікери, контакти, FAQ)
assets/js/app.js      спільне: дати, UTM, меню, підстановка контактів
assets/js/home.js     розклад і фільтри на головній
assets/js/course.js   заповнення сторінки курсу
assets/js/form.js     форма реєстрації (розмітка + логіка)
api/lead.js           Vercel-функція: приймає заявку → пересилає у webhook
vercel.json           rewrites і кешування
```

---

## Що потрібно заповнити перед запуском реклами

Усе — у файлі `assets/js/data.js`, блок `site` на початку:

- [ ] `phone` і `phoneHref` — реальний номер
- [ ] `viber` — посилання на чат
- [ ] `telegram` — або залиште `''`, тоді кнопка зникне сама
- [ ] `email`
- [ ] ціни курсів — поле `price` у кожному курсі (зараз `null`,
      і сайт показує «Вартість — уточнюємо у Viber»)
- [ ] адреси локацій — поле `venue` у кожному курсі
- [ ] програми для Power Endo, гігієни, складної ендодонтії та переліковування —
      масив `program` у відповідному шаблоні. Поки він порожній, на сторінці курсу
      показується блок «Повну програму надсилаємо особисто» з кнопкою.

## Як додати нову дату

Один рядок у масив `courses` в `data.js`:

```js
{ slug:'endo-odesa-2027-02-06', date:'06.02.2027', city:'Одеса', venue:'',
  title:'Ендодонтія. Сучасні протоколи', topic:'endo', speaker:'noienko',
  template:'primaryEndo', price:null, seats:null, source:'' }
```

`slug` має бути унікальним. Місто й тема автоматично зʼявляться у фільтрах.
Дати, які вже минули, ховаються самі — видаляти їх не потрібно.

## Як додати спікера

1. Покладіть фото у `assets/images/` (PNG з прозорим фоном, ~600×900).
2. Додайте запис у `speakers` в `data.js`.
3. Вкажіть його ключ у полі `speaker` потрібних курсів.

## Форма реєстрації

Два кроки.

**STEP 1 — лід.** Ім'я, телефон, email (необов'язковий). Курс береться
зі сторінки й повторно не питається. Заявка зберігається одразу
(`stage: "lead"`), тут же спрацьовує Meta-подія `Lead`.

**STEP 2 — оформлення.** Показується після подяки, за кнопкою
«Продовжити оформлення»: ПІБ, статус, БПР, освіта, спеціальність тощо
(`stage: "registration"`, подія `CompleteRegistration`).

Сенс поділу: контакт зафіксований до того, як людина побачить довгу форму.
Якщо вона закриє вкладку на другому кроці, лід у вас уже є.

У CRM орієнтуйтесь на поле `stage` і дедуплікуйте за `phone` + `course_id`.

Окремий тип ліда — блок підбору курсу на головній: `lead_type: "course_selection"`,
одразу після STEP 1 без другого кроку.

### Що приходить у webhook

`stage`, `lead_type`, `course_id`, `course_name`, `course_city`, `course_date`,
`name`, `phone`, `email`, `fullnameUa`, `status`, `bpr`, `fullnameEn`, `dob`,
`education`, `specialty`, `workplace`, `position`, `groupList`, `comment`,
`page_url`, `created_at`, `referrer`, `utm_source`, `utm_medium`, `utm_campaign`,
`utm_content`, `utm_term`, `fbclid`, `gclid`.

## Запуск локально

```bash
python3 -m http.server 8000
```

Далі `http://localhost:8000`. Локально й на GitHub Pages форма працює в demo-режимі:
заявка не відправляється, а виводиться в консоль браузера (F12 → Console).

## Заявки в Google-таблицю

Покрокова інструкція — у файлі **`N8N.md`**.
Готовий воркфлоу — `n8n-workflow.json`, заголовки таблиці — `n8n-headers.txt`.
Альтернатива без n8n — скрипт `apps-script.gs`.

### Варіант без n8n

1. Створіть таблицю, перший аркуш назвіть **Ліди**.
2. Розширення → Apps Script → вставте вміст файлу `apps-script.gs`.
3. Розгорнути → Веб-застосунок (виконувати від себе, доступ — усі).
4. Скопіюйте URL і додайте його у Vercel як `LEAD_WEBHOOK_URL`.

Обидва кроки форми надсилають один `lead_id`. Скрипт знаходить рядок
за цим id і **доповнює** його, а не створює новий. У колонці «Статус»
видно, чи людина дійшла до кінця: «Тільки контакти» або
«Реєстрація завершена».

## Viber-групи

Посилання лежать у `data.js` → `viberGroups`:
- `primaryEndo` і `complexEndo` — своя група в кожному місті
- `byTemplate` — одна група на весь курс (Power Endo, лекція, мікроскоп)

Після завершення реєстрації людину перекидає у групу свого курсу й міста
через 5 секунд, плюс є кнопка для переходу вручну.

## Deploy на Vercel (робочий варіант)

1. Import репозиторію у Vercel.
2. Settings → Environment Variables → додати `LEAD_WEBHOOK_URL`.
3. Deploy.

Сторінки курсів доступні і як `/course.html?slug=...`, і як `/kurs/<slug>`.

## Deploy на GitHub Pages (тільки прев'ю)

Завантажте вміст папки в корінь репозиторію, увімкніть Pages для `main / (root)`.
Файл `.nojekyll` уже на місці. Заявки в цьому режимі не відправляються.

## Meta Pixel

Хелпер уже вбудований у `app.js`. Після отримання Pixel ID вставте стандартний
код Meta у `<head>` обох сторінок — події почнуть відправлятися автоматично:

| Подія | Коли спрацьовує |
|---|---|
| `ViewContent` | перегляд каталогу або сторінки курсу |
| `InitiateCheckout` | відкриття форми |
| `InitiateCheckout` | людина залишила контакти (крок 1) |
| `Lead` | усі дані внесені (крок 3) |

Піксель `1516093250283344` уже вставлений в обидві сторінки.

Ті самі події дублюються в `dataLayer` для Google Tag Manager.
